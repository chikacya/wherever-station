# Security policy / 安全策略

## Report a vulnerability

Please do not open a public Issue for vulnerabilities, real subscription URLs, API tokens, private keys, complete proxy URIs, or server credentials. Use GitHub's private vulnerability reporting for this repository. If that feature is unavailable, contact the maintainer through the private channel listed on the GitHub profile and include only the minimum reproduction material.

Supported security fixes target the latest published release. Reports should include the affected version, impact, reproduction steps using synthetic data, and any suggested mitigation. Do not test against infrastructure that you do not own or have permission to operate.

## 报告安全问题

请勿在公开 Issue 中提交漏洞细节、真实订阅地址、API Token、私钥、完整代理 URI 或服务器凭据。优先使用本仓库的 GitHub Private vulnerability reporting；如果该功能不可用，请通过维护者 GitHub 主页列出的私密渠道联系，并只提供复现所需的最少资料。

安全修复以最新正式 Release 为支持目标。报告应包含受影响版本、影响范围、使用虚构数据的复现步骤和可选的缓解建议。请勿测试未经授权的服务器或网络。
