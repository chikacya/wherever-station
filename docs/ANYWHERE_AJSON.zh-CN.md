# Anywhere AJSON 订阅

适配依据为 Anywhere 2.5(411) 源码中的 `Documentations/AJSON.md`、`AJSONParser.swift` 和 `SubscriptionFetcher.swift`，格式版本为 `anywhere: 1`。客户端是否支持以请求能力头为准，不根据操作系统或 User-Agent 猜测。

## 使用

新版 Anywhere 请求携带 `X-Anywhere-Format: ajson/1` 时，原有自动订阅或 `format=anywhere` 地址返回 AJSON。旧客户端没有该头时继续获得 Base64；显式 `format=base64` 始终保留旧格式。其它客户端的显式格式不受协商影响。

订阅页提供 `ajson` 链接和“下载 .ajson”。文件是标准 JSON（也是客户端 JSON5 解析器可接受的子集）；识别不依赖 URL 后缀。访问权限、token、到期和流量策略与原订阅一致，响应 no-store，协商响应声明 Vary。

## 本轮功能

- 名称、流量、额度和到期写入文档；使用现有流量核算口径，不把主机累计流量伪称为单订阅独占用量。
- 节点优先使用原生结构化字段，覆盖 Nowhere（NW3）、VLESS、Hysteria2、Sudoku、Trojan、AnyTLS、Shadowsocks、SOCKS5 和 RFC。ID 来自节点记录，名称和排序改变时保持 ID。未知、重复或无法无损转换的 URI 参数保留为 `{id, name, link}`。历史记录不自动删除，但不再提供 NW2 导入或管理适配。
- 不支持的 URI scheme 会跳过，预检和响应头显示数量。重复/缺失 ID 或完全没有兼容节点时拒绝生成，不发送会清空客户端列表的空订阅。
- 订阅编辑器的“Anywhere 原生参数与订阅图标”提供单个订阅图标、按协议内置预设、自建 JSON 模板、按节点高级参数和完整输出检查。设置跟随订阅保存、历史版本和可移植备份；仅影响 AJSON，不修改服务器或其它客户端格式。

首次从旧链接订阅切换到带 ID 的 AJSON，Anywhere 会重建一次节点身份；后续更新才使用稳定身份。同一 ID 在不同订阅下属于不同客户端节点。服务端删除再新建节点会生成新 ID，因此它也会成为新身份。

AJSON 当前只承载订阅元数据和节点，不承载代理组、DNS、分流、MITM，也没有 Nowhere pin 字段。规则仍通过 .arrs/.amod；不能利用 AJSON 给 Nowhere 下发一个客户端不支持的证书 pin。

## 原生设置与图标

图标支持 PNG/JPEG/WebP，最多 256 KiB。只需上传一个图标，可以预览、更换或移除；输出时自动为所有外观复用。已有设置优先沿用原浅色图标，没有时使用原深色图标。

模板只允许高级参数，不能覆盖节点 ID、名称、地址、端口、协议或凭据。例如：

```json
{
  "quiet": { "morph": false, "morphPrelude": "fade" },
  "xhttp": { "transport": { "type": "xhttp", "path": "/x", "mode": "auto", "xmux": { "maxConcurrency": "16-32" } } }
}
```

参数模板是可复用的客户端高级配置，不是服务器部署方案。旧订阅默认“沿用节点参数”，无须使用模板。选择节点后，下拉框会提供该协议的内置预设；选择后可查看参数和适用说明。内置预设保存到当前订阅，后续可以在“管理订阅模板”中修改或自建模板；节点高级参数与模板递归合并，节点参数优先。仅引用的模板会写入最终订阅。支持 Nowhere `morphPrelude`、VLESS TLS/Reality/ECH 和 WS/gRPC/XHTTP、Hysteria2 拥塞控制和 Gecko、AnyTLS 会话、Sudoku 编码/复用/HTTP mask 等原生能力。高级选项不会替你更改服务端，需与服务端配置和客户端能力匹配。

“节点高级参数”可展开编写节点覆盖；“恢复节点参数”清除此节点的模板引用和高级覆盖。使用“检查 AJSON 输出”查看原生节点和原始链接数量，并可展开包含凭据的完整 JSON。未知 URI 参数的节点无法应用高级覆盖，避免丢失原始配置；可清除此节点原生设置恢复原始链接。非法 JSON、字段类型或跨协议参数会阻止保存。


## 可视化连接设置

选择节点后，“当前生效配置”会自动检查并显示最终合并后的传输方式、连接安全、路径等信息。原始链接透传的节点会明确标注，无法确认的配置显示错误，不用模板名称推测连接方式。

“自定义连接设置”默认折叠，常用选项使用下拉框和输入框；不填写时沿用模板或节点。已有节点无需调整即可继续使用。“恢复节点参数”清除该节点的模板引用和单独设置，保留其他节点。

JSON 覆盖和订阅模板管理统一放在“专家模式（JSON）”中，默认隐藏。切换预设时，如当前节点存在单独设置，会先提示替换或保留；确认替换后清除旧覆盖，避免选中的预设被旧参数覆盖。预设仅修改客户端订阅，不更改服务器。


## 从图标库选择

图标设置保留本地上传，并新增“从图标库选择”。支持 Orz-3 四组图库、QQ 经典、QureColor All、Semporia、shindgewongxj、TheMagic、tugepaopao、可爱卡通、彩色静态旗帜、暴怒表情和角色，共 14 个来源。选择器中可按名称搜索、翻页、预览和应用；来源与作者链接指向原图库。

只有打开选择器后才加载图库代码和当前图库的清单，清单缓存 30 分钟；每页最多 36 个图标，缩略图懒加载。切换图库和关闭面板会取消未完成的下载，加载失败可重试。取消或按 Escape 关闭图库不会关闭订阅编辑器，也不会替换原图标。选定后点击“使用此图标”只修改订阅草稿，仍需保存订阅。

浏览时由浏览器直连 GitHub/GitLab，不发送 Komari 凭据或订阅 token。GitLab 使用同仓库的 API 原始文件接口以支持跨域读取。应用时将图片缩放至最长边不超过 256 像素，转换为 PNG 嵌入订阅，两个外观共用；订阅客户端不需要访问第三方图库。清单下载最多 1 MiB、选中图片最多 2 MiB，下载超时 12 秒；输出仍遵守 256 KiB 图标上限。


图库仅在网格上方提供带文字的翻页按钮，并显示图标总数、当前范围和总页数。缩略图在进入可视区域后加入最多 4 路并发的加载队列；短暂失败自动重试两次，成功图片使用最多 96 张、12 MiB 的缓存。同一 URL 的网格、预览与应用操作共享下载，取消某个使用方不会中断仍被其他位置使用的请求。404/410 显示“链接失效”，其他失败显示“加载失败”，不再使用含义不明的问号。“重试本页图片”仅重新请求失败图片，已成功加载的图片继续复用缓存；翻页和关闭面板会取消已无用的请求。

订阅卡片会直接展示已保存的订阅图标；未设置、移除或图片无法解码时使用默认链接图标。卡片读取订阅内嵌图片，无需重新访问第三方图库。
