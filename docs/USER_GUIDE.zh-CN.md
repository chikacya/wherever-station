# 使用指南

[English](USER_GUIDE.md)

## 选择起点

空白工作台提供三条互不依赖的路径：

1. 已经有客户端 URI、Base64 列表或 Clash/Mihomo YAML 时，选择**导入节点**。
2. 已经由 S-UI 或 2S-UI 管理 sing-box 时，选择**连接外部面板**。
3. 需要 Komari 监控、服务发现、连接检查或托管部署时，选择**接入 VPS**。

节点不需要关联服务器也可以进入订阅。

## 服务器与流量

服务器工作台把 Komari 指标和 Wherever Station 资料放在同一页。选择服务器后可查看实时上下行、CPU、内存、磁盘、24 小时趋势，以及已识别的代理服务。

服务器流量计划是可选功能。可以设置额度、计费口径（上下行相加、取较大值、仅上传或仅下载）、重置日和提示阈值。它使用 Komari Agent 计数器，并可同步 Komari Client 的流量上限。超过服务器额度只提示，不会停止进程或停用订阅。

服务器流量计划和订阅额度是两套数据：

- 服务器计划描述 VPS 套餐流量。
- 订阅额度决定某一条公开订阅 URL 是否继续可用。

**发现节点**用于检查已有 sing-box 或 Nowhere 服务，不会修改它们的配置。缺少公网地址、凭据、TLS 或 Reality 信息的候选会成为待修复草稿。完整的 Nowhere 结果可以先建立停止状态的接管副本，再由用户从部署页明确切换；建立副本不会停止原服务。

可选的 **IP 质量 / 解锁能力** 检查会在所选 Agent 上运行内置并发探针，汇总出口地区、ASN/ISP、网段、风险特征、多数据源出口一致性，以及常用流媒体与 AI 服务的可达性和响应时间。探针只在用户点击时运行，带有短超时且不会常驻；结果只代表检测当时的网络状态，风险标签也可能因不同数据源的口径而不同。

## 节点库

批量导入支持：

- 一条或多条客户端 URI；
- Base64 编码的 URI 列表；
- Clash/Mihomo YAML。

保存前先检查解析结果。关联服务器只是归类和远程操作字段，可留空。

节点库支持复制 URI、单节点二维码、筛选、排序、批量启停、标签、迁移宿主、正则替换和命名模板。默认名称会跟随所选服务器；用户手动改名后不再自动覆盖。顶部的隐私模式可以在截图前隐藏节点地址、服务器 IP 和来源 URL，关闭页面后不会改变保存的数据。

未知 URI scheme 会作为不透明值保存，可以进入 URI 类输出，但不会被自动转换为结构化配置。

## 外部订阅源

在**订阅源**中添加机场或自建 HTTP(S) 订阅。同步请求由 Komari 主控发出；可选的服务器归属不参与代理请求。

首次同步创建节点，之后按规范化连接指纹更新；已由发现导入或其他来源收录的同一连接会跳过，不会再建立副本。上游消失的节点会停用而不是直接删除。如果响应带有 `Subscription-Userinfo`，来源卡片会显示上传、下载、剩余量和到期时间。

订阅源 URL 属于凭据，不要在截图、日志或 Issue 中泄露。

## 创建订阅

1. 新建订阅并选择节点。
2. 通过点击或拖动调整节点顺序。
3. 按需创建 `select`、`url-test`、`fallback` 或 `load-balance` 代理组。
4. 按需选择基础分流、手写规则或缓存规则集。
5. 预览变化和格式兼容性。
6. 保存后，为目标客户端复制链接或二维码。

代理组和规则用于 Mihomo、Surge、Loon、sing-box 等结构化输出。Anywhere 等 URI 列表客户端只接收节点，不接收这些结构。

订阅可以不限制额度，也可以使用手动额度、跟随一个外部订阅源，或跟随一个 Provider 客户端。到期或耗尽只关闭公开订阅响应，节点记录和代理进程继续运行。

设备档案用于记录客户端及推荐输出格式。生成前应查看预检：结构化格式不支持的协议会被明确跳过，不会猜测转换。

## 托管部署

部署页提供少量常见 sing-box 预设和较完整的 Nowhere 流程，适合简单隔离实例，不是任意 sing-box 配置编辑器。

创建前需要：

- 选择已绑定 Agent 的服务器；
- 确认公网域名或 IP 与未占用端口；
- 选择内核来源和版本；
- 在需要 TLS 时选择证书方式；
- 检查生成计划。

创建后服务保持停止。用户需要主动启动、自行开放防火墙端口，并执行真实连接检查。

VLESS Reality 不要求自有域名或部署 PEM 证书，但仍依赖 Reality 密钥、SNI 和 TLS 握手目标。Hysteria2、TUIC、Trojan 和 AnyTLS 需要可信证书，或由客户端明确接受私有证书。

## 证书

证书工作台按服务器归属：

- **稳定自签**：在托管证书目录创建证书和私钥。
- **已有 PEM**：登记绝对路径，并检查可读性、密钥匹配、SAN、指纹和到期时间。
- **Nowhere 临时 TLS**：适合测试，但重启后指纹可能变化。

私钥内容不会返回浏览器，也不会进入插件状态。被实例引用的证书不能直接删除，需要先给实例切换证书。

Wherever Station 不签发公网 ACME 证书。需要可信证书时，请使用 ACME 客户端或专业面板，再登记生成的 PEM 路径。

## S-UI 与 2S-UI

在远端面板创建 API Token，然后在**外部面板**填写 HTTPS 根地址、面板路径、类型和 Token。连接检查与同步使用 `/apiv2`，不会写远端配置。

Wherever Station 导入面板客户端暴露的分享链接。只有入站、没有客户端或分享链接时，还不是完整节点；应回原面板完成客户端绑定，再同步一次。

外部面板节点即使没有分配 VPS，也可以使用**识别地区**补全展示地区。系统先解析节点域名，只把得到的公网 IP 交给地理信息服务，保存 ISO 国家代码与 ASN；不会修改原分享 URI。

远端节点消失后，可以选择停用并保留、删除本地记录，或脱离来源转为手动节点。协议、用户、路由和证书配置仍由原面板维护。

## 状态、遥测与连接检查

三者回答不同问题：

- **服务状态**：进程是否运行。
- **遥测**：已知进程此刻在做什么。
- **连接检查**：真实客户端配置能否完成请求。

内核支持相应接口时，Nowhere 会显示协议遥测；sing-box 卡片显示宿主能够提供的进程 CPU、内存、PID 和流量证据。连接检查在选定 Agent 上运行临时客户端，不是持续测速。

## 设置与草稿

全局设置包含跨页面偏好和**备份与迁移**。先下载 JSON 备份，再在新安装中选择文件、核对替换数量并确认恢复。备份包含节点 URI、订阅 Token、外部面板 API Token 和规则集缓存，请作为私密文件保管。

恢复只替换插件记录，不安装 Komari Agent、不迁移证书/私钥文件或代理内核，也不会启停服务。迁移到另一套 Komari 后，操作实例前请核对 Agent 绑定、订阅公开地址、证书路径和托管实例状态。覆盖已有数据前，建议先导出一份当前备份。

节点、证书、Provider 和实例选项仍留在各自流程。

长表单会在当前浏览器标签页保留未完成草稿。关闭再打开可以恢复；保存或点击**放弃草稿**后删除。Provider API Token 不会进入草稿。关闭浏览器标签页会清除会话草稿。
