# 1. Getting started

[Index](README.md) · [Next: Servers](02-servers.md)

Choose one independent entry path: import existing links under **Nodes**, connect S-UI/2S-UI under **Providers**, or onboard a Komari Agent under **Servers** for monitoring, discovery and managed deployment. Nodes do not need a server assignment to enter a subscription.

The header offers a full-screen page, Settings, theme cycling, and Komari connection status. The latter only proves that the plugin API is reachable; it does not mean every Agent is online. Navigation contains Servers, Nodes, Subscriptions, Sources, Deploy and Providers.

Green means online/running/reachable, amber means attention or disagreement, red means failure/restriction, and gray means unknown. Text always accompanies color. Privacy mode hides addresses and source URLs for screenshots but does not alter saved data. Long forms keep a tab-scoped draft; saving, discarding, or closing the browser tab clears it. Provider tokens are never placed in drafts.

Deployment, service control, upgrades, certificate inspection and connectivity checks execute through a bound Agent. If a remote task times out, refresh its status before trying again; do not assume it was never submitted.
