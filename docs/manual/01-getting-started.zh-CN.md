# 1. 开始使用与界面约定

[目录](README.zh-CN.md) · [下一章：服务器](02-servers.zh-CN.md)

## 选择起点

空工作台有三条互不依赖的入口：已有分享链接时到**节点 → 导入节点**；已有 S-UI / 2S-UI 时到**外部面板**；需要监控、发现或托管部署时先到**服务器 → 接入 VPS**。节点不必绑定服务器也能制作订阅。

## 顶栏

- **全屏**：从 Komari 内嵌页打开独立页面，适合窄屏和下载备份。
- **设置**：公共订阅根地址、监控阈值、主题和备份迁移。
- **主题**：在跟随 Komari、浅色和深色间循环。
- **Komari 已连接**：表示页面能够调用 Komari 插件接口，不等于所有 Agent 在线。

## 导航和状态

顶部依次为服务器、节点、订阅、订阅源、部署节点和外部面板。绿色通常表示在线、运行或可达；黄色表示等待确认、来源分歧或旧缓存；红色表示失败、受限或超额；灰色表示未知或没有数据。状态旁始终有文字，不需要只靠颜色判断。

## 隐私模式

节点页的隐私开关会遮挡服务器 IP、节点地址和来源 URL，适合截图。它只改变当前浏览器中的显示，不修改已保存数据，也不能移除二维码或已复制文本中的凭据。

## 表单草稿

较长的编辑窗口会在当前浏览器标签页保存草稿。关闭窗口后再次打开可以继续；保存或点击**放弃草稿**会清除。Provider Token 不写入草稿，关闭整个标签页后会话草稿也会清除。

## 保存和远程操作

普通资料编辑先更新插件数据库。部署、启停、升级、证书检查和连接测试会通过绑定的 Komari Agent 在 VPS 上执行，并要求相应系统权限。远程任务进行中不要重复点击；页面超时不代表可以安全重复执行，应先刷新实例状态。
