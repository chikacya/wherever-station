# 2. 服务器 Tab

[上一章](01-getting-started.zh-CN.md) · [目录](README.zh-CN.md) · [下一章：节点](03-nodes.zh-CN.md)

服务器页把 Komari 主机指标、Wherever Station 资料和代理服务放在一个工作台中。

![服务器工作台](../assets/screenshots/overview-light.png)

## 页面卡片

- **服务器 / 在线 / 本月流量 / 可用节点**：全局汇总；本月上下行来自 Komari 计数器。
- **当前吞吐量**：所有在线 Agent 的实时上传和下载总和，不是某个代理进程的流量。
- **60 秒趋势**：在线服务器总流量的短期变化。
- **服务器索引**：选择当前服务器；旗帜和地区来自服务器资料，不用于证明出口位置。
- **所选服务器**：CPU、内存、磁盘、实时速率、节点数量和操作入口。
- **24 小时历史**：按需加载当前服务器历史趋势；刷新按钮重新读取。
- **月度流量**：按服务器显示当月用量，点击柱子可切换所选服务器。
- **进程遥测**：展示发现或托管的 sing-box / Nowhere 服务状态；Nowhere 支持时可进入实时遥测。

## 接入 VPS

点击**接入新 VPS**，填写 Komari API 地址和一次性注册码，复制生成的 Agent 安装命令到目标机执行。Agent 上线后点击**刷新 Agent**，再补充名称、国家代码、地区、服务商和公网地址。服务器资料仅用于归类；实际指标和远程命令仍以 Komari Client ID 为准。

## 服务器操作

- **在此部署**：切换到部署页并预选服务器。
- **发现节点**：只读扫描服务、进程和常见配置，不修改远端。
- **刷新状态**：重新读取 Agent 与代理进程状态。
- **编辑**：修改显示资料和 Agent 绑定。
- **删除**：移除插件中的服务器资料；先确认其节点和托管实例是否仍被使用。

## 流量计划

为单台服务器设置套餐额度、统计口径、重置日和提醒阈值。可选口径包括上下行相加、取较大值、仅上传或仅下载。超过额度只提示，不停止进程，也不关闭订阅。若服务器绑定 Komari Client，可把额度同步给 Komari。

## IP 快速检测

点击检测后，Agent 会短暂请求多个公开服务：分别展示 IPv4、IPv6 和各自数据库地区；网络身份和纯净度只绑定标题所示的地址；服务“可达”只说明网页端点响应，不保证账号、播放或地区解锁。来源列表按地址分组，同一地址的数据库国家不一致时才提示“地区有分歧”。这是一项快速参考，不替代专业检测站。

## 发现现有节点

填写公网域名或 IP 后扫描。结果分为：

- **可导入**：参数足以生成完整客户端 URI。
- **待确认**：缺少 SNI、Reality 公钥、用户凭据等客户端侧信息。
- **草稿**：可以保留到节点页继续补全。
- **Nowhere 原生发现**：可直接导入；满足条件时还能建立停止状态的托管副本，之后再明确切换接管。

扫描不会把监听地址自动当成 SNI，也不会猜测证书和 Reality 参数。无法从服务端配置可靠得到的字段应填写原始 URI。

## 服务控制与遥测

宿主原生服务可以启动、停止和重启；若该服务已被转换为托管实例，入口会引导到部署页。Nowhere 实时遥测显示速率、累计流量、连接和协议状态；sing-box 在没有原生流量接口时仅显示进程 CPU、RSS、PID 等宿主证据。
