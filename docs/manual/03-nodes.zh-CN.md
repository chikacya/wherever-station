# 3. 节点 Tab

[上一章](02-servers.zh-CN.md) · [目录](README.zh-CN.md) · [下一章：订阅](04-subscriptions.zh-CN.md)

节点库是所有来源的统一资料库。手动、订阅源、外部面板、发现和托管部署最终都会形成节点记录。

![节点管理](../assets/screenshots/nodes-light.png)

## 添加与编辑

点击**添加节点**可填写名称、完整 URI、服务器归属、标签和输出状态。URI 是事实来源；协议、地址等字段由 URI 解析。关联服务器用于分组与远程检查，可留空。修改宿主不会改写 URI 中的服务器地址。

## 批量导入

支持逐行 URI、Base64 URI 列表和 Clash/Mihomo YAML。先点击**解析并预览**，检查名称、协议和重复项，再选择导入。相同规范化连接不会重复创建；未知 scheme 可原样保存并直出，但不能保证转换到结构化格式。

## 搜索与筛选

可按名称、地址和协议搜索，并按地区、协议、来源、服务器和输出状态筛选。列表可排序；选择框用于批量操作。国家展示统一为国旗加 ISO 两字母代码。

## 每个节点的操作

- **输出开关**：控制是否允许进入订阅；已在某个订阅中选中但被停用的节点不会输出。
- **直出**：查看并复制原始 URI，或显示单节点二维码。
- **连接检查**：运行临时客户端并请求 HTTPS 测试地址，验证真实代理出口。
- **编辑**：修改名称、URI、宿主与标签。
- **删除**：从节点库、订阅和代理组引用中移除。

## 连接检查为什么选择 Agent

检查需要在某台 VPS 上运行临时客户端。系统优先使用另一台在线 Agent，避免“服务端自己连接自己”的误判；没有异地 Agent 时才使用节点宿主。结果回答的是这条客户端 URI 能否建立代理请求，不是普通 TCP 端口探测。

## 批量整理

选中节点后可执行：按模板整理名称、仅添加国旗、正则重命名、移动宿主、替换标签、连接检查、允许/停止订阅输出和删除。应用前会显示预览；批量移动宿主不会修改 URI。

## 待修复节点

发现扫描不能可靠生成 URI 时会进入草稿区。点击**补全**填写公网地址、端口、凭据、SNI/证书域名，以及 Reality 公钥或完整 URI。完整 URI 优先级最高。验证成功前草稿不会进入订阅。

## 来源与去重

来源标识包括手动、导入、订阅源和外部面板。同一规范化 URI 从多个入口出现时只保留一条节点，避免机场订阅与发现扫描重复。上游节点消失时通常先停用并保留记录，是否删除由对应来源页决定。
