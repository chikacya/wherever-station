# 4. Subscriptions tab

[Previous](03-nodes.md) · [Index](README.md) · [Next: Sources](05-sources.md)

A subscription selects nodes and exposes client-specific URLs. Its card can copy or show a QR code, enable/disable output, edit, run compatibility preflight, inspect history, manage device profiles, rotate the token or delete the subscription. Token rotation immediately invalidates old URLs; deleting a subscription does not delete nodes.

Basic settings include name, optional expiry and quota. Quota can be unlimited, manual, inherited from one external source, or inherited from one provider client. Expiry or exhaustion disables only that public URL. Upstream allowances are not added together.

In **Node scope**, click nodes to include them; desktop users can drag and sort, while mobile favors taps and dedicated handles. Filters include country, VPS and protocol. **Groups** support `select`, `url-test`, `fallback` and `load-balance`, generated by country/host or assembled manually. **Rules** combine a base policy, manual domain/CIDR rules and successfully cached remote rule sets.

Groups and rules apply to structured Mihomo, Surge, Loon and sing-box outputs. URI-list clients such as Anywhere receive nodes only. Before saving, a change review shows before/after counts. Preflight lists included and skipped nodes for every format; it verifies serialization, not network reachability. Device profiles remember the appropriate format for a named client and produce its copy/QR action.
