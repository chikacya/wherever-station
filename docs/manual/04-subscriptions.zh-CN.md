# 4. 订阅 Tab

[上一章](03-nodes.zh-CN.md) · [目录](README.zh-CN.md) · [下一章：订阅源](05-sources.zh-CN.md)

订阅把节点库中的一部分节点组合为客户端可读取的公开地址。

## 订阅卡片

- **复制**：复制默认订阅地址。
- **二维码**：显示订阅 URL，适合移动端扫码。
- **启用/停用**：停用后 URL 返回不可用，但节点与进程不受影响。
- **编辑**：进入三步编排。
- **检查**：对各输出格式做兼容性预检。
- **历史**：查看不含凭据的版本摘要并恢复旧结构。
- **设备**：记录常用客户端并给出推荐格式。
- **轮换 Token**：使旧 URL 失效并生成新地址。
- **删除**：删除订阅，不删除节点。

## 基本资料与额度

填写名称、可选到期日和启用状态。额度可设为不限、手动额度、跟随外部订阅源，或跟随外部面板客户端。到期或耗尽只让该订阅 URL 失效；不会停止节点。多个上游额度不会自动相加。

## 第一步：节点范围

右侧节点库支持搜索以及按国家、VPS、协议等快速分类。点击节点即可加入/移除；桌面端可拖入左侧并排序，移动端以点击为主、拖动把手用于精确排序。**全部纳入订阅**和**清空节点**只影响当前编辑中的订阅。

## 第二步：代理组

可创建：手动选择 `select`、自动测速 `url-test`、故障转移 `fallback`、负载均衡 `load-balance`。代理组可以自动按国家或宿主生成，也可手动命名、排序和选择节点。代理组只会进入 Mihomo、Surge、Loon、sing-box 等结构化输出；URI 列表格式只输出节点。

## 第三步：分流规则

选择基础策略、手写域名/CIDR 规则，或启用订阅源页缓存成功的远程规则集。规则顺序会影响匹配结果；远程规则刷新失败时继续沿用最后成功缓存。Anywhere 节点文件夹不使用这些规则。

## 预览与保存

点击保存前会出现变更预览，显示节点、代理组、规则和设备数量的前后差异。保存后才会修改公开输出。长表单可恢复会话草稿。

## 客户端兼容预检

预检逐格式列出纳入和跳过的节点，并说明原因。它检查序列化能力与必要字段，不执行网络连接；真实可用性请回节点页运行连接检查。通过的格式可以直接复制 URL，也可下载预检报告。

## 设备档案

为 iOS/Android Anywhere、Mihomo、Surge、Loon、sing-box 或通用客户端保存名称和类型。设备档案不控制访问权限，只帮助用户每次复制正确格式。二维码与 URL 都包含订阅 Token。
