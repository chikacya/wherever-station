# 5. 订阅源 Tab

[上一章](04-subscriptions.zh-CN.md) · [目录](README.zh-CN.md) · [下一章：部署节点](06-deployment.zh-CN.md)

订阅源页包含两类远端输入：节点订阅和纯文本规则集。

## 添加节点订阅源

填写名称、HTTP/HTTPS URL、刷新间隔和可选服务器归属。服务器归属只用于节点分类，不会让请求通过那台 VPS。URL 通常包含凭据，截图前请开启隐私模式。

## 同步行为

点击**立即同步**后由 Komari 主控获取内容，支持 URI、Base64 与 Clash/Mihomo YAML。首次同步创建节点，之后用规范化连接指纹更新；与手动导入、发现或其他来源相同的连接会跳过。远端删除的节点会停用而非立刻删除，以便复核。

卡片显示节点数量、间隔、上次时间和错误。若响应含 `Subscription-Userinfo`，还会显示上传、下载、剩余量和到期日。同步错误不会删除上次成功节点。

## 编辑与删除

编辑 URL 后，下次成功同步才更新节点。删除来源时，已同步节点会保留并转成普通外部节点，不再自动更新。

## 远程规则集

点击**添加规则集**填写名称、纯文本 URL、默认动作（代理、直连或拒绝）。刷新成功后缓存域名/CIDR 条目，订阅编辑器才能选择它。若刷新失败但存在旧缓存，输出继续使用旧版本；删除规则集会同时移除订阅中的引用。

## 何时使用哪种入口

- 机场或自建订阅 URL：节点订阅源。
- S-UI / 2S-UI：外部面板，而不是这里。
- 单条或一次性节点列表：节点页批量导入。
- 分流域名和 CIDR 文本：远程规则集。
