# 6. 部署节点 Tab

[上一章](05-sources.zh-CN.md) · [目录](README.zh-CN.md) · [下一章：外部面板](07-providers.zh-CN.md)

部署页管理 Wherever Station 自己创建或接管的隔离实例。它不是完整的 sing-box 专业面板。

![部署节点](../assets/screenshots/deploy-light.png)

## 页面入口

- **部署 Nowhere**：完整的 Nowhere 创建、版本、证书、遥测和生命周期流程。
- **部署 sing-box**：用快捷预设创建常见协议实例。
- **发现现有节点**：选择服务器进入与服务器页相同的只读扫描。
- **证书工作台**：生成稳定自签证书或登记目标机已有 PEM。
- **管理预设**：新建、复制、隐藏、导入或导出 sing-box 预设。

## 创建 Nowhere

选择服务器、名称、公网地址、监听端口、客户端输出和证书方式，再填写共享密钥。高级运行参数包含限速、拨号、SOCKS、日志、遥测间隔、Vector 参数、Morph、传输内存策略和兼容扩展环境变量。官方 Release 只有进入已验证适配清单后才能部署；新发现但未验证的版本只读显示。

证书可选择临时自签、为实例生成稳定自签、目标机已有 PEM，或复用证书工作台资产。预览只验证参数能否生成；**检查并创建（不启动）**会远程检查端口、安装内核、写隔离配置并建立 systemd unit，但保持停止。

## 创建 sing-box

先选预设，再选择内核来源、服务器、公网地址、端口和协议参数。内置预设覆盖 VLESS Reality、Shadowsocks、Hysteria2、TUIC、Trojan、AnyTLS 等常见场景；它们是快捷起点，不代表权威推荐。TLS 协议需选择自签、已有 PEM 或证书资产。创建前执行端口冲突检查和 `sing-box check`，失败会把错误留在对应表单中。

## 实例卡片

- **启动 / 停止 / 重启**：控制该隔离 systemd unit。
- **测试连接**：使用生成的客户端配置实际请求测试地址。
- **加入订阅**：把对应节点加入已有或新订阅。
- **编辑运行配置**：读取远端当前配置，可修改创建时的连接、Carrier、客户端输出、证书和高级运行参数，检查后原子应用；失败时恢复原配置。所属 VPS、实例身份、内核来源和接管来源不会在这里改动。
- **版本与证书**：Nowhere 版本切换、证书指纹、SAN 和有效期。
- **实时遥测**：Nowhere 当前速率和历史曲线；移动指针可查看具体值。
- **刷新 / 日志 / 复制 / 二维码 / 删除**：状态维护与单节点输出。删除会移除托管服务文件，执行前应确认。

## Nowhere 接管

原生发现的 Nowhere 可以先生成停止状态的托管副本。此时原服务仍运行。核对副本后点击**切换接管**，系统停止原 unit、启动托管 unit并保存回滚信息；失败会尝试恢复原服务。通过次级操作**退出接管并恢复原服务**可撤销接管。托管配置的修改不会反写原服务，因此退出接管仍会恢复原来的配置。接管前后端口不能由两个 unit 同时占用。

## 证书工作台

**生成稳定自签证书**会在插件托管目录保存证书与私钥；**登记已有 PEM**只保存路径并检查可读性、私钥匹配、SAN、指纹和期限。私钥内容不返回浏览器。被实例引用的证书不能删除。公网可信证书仍应由 ACME 客户端或专业面板签发。

## 防火墙和安全

插件不会替用户开放云防火墙或系统防火墙。创建并启动后仍需确认端口允许入站。自签节点要求客户端显式信任或允许不安全连接；Reality 不需要自有 PEM，但仍依赖正确的 SNI、密钥和握手目标。
