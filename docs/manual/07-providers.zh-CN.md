# 7. 外部面板 Tab

[上一章](06-deployment.zh-CN.md) · [目录](README.zh-CN.md) · [下一章：设置](08-settings.zh-CN.md)

外部面板用于只读接入 S-UI 和 2S-UI，把面板已经生成的分享链接同步到节点库。

## 连接面板

点击**连接专业面板**，填写显示名称、面板类型、HTTPS 根地址、可选面板路径和 API Token。保存前会检查 `/apiv2`。Token 只保存在服务端；编辑时留空表示沿用原 Token。

## 检查与同步

- **检查**：验证地址、Token 和 API 响应，不修改本地节点。
- **同步**：读取客户端分享链接，先展示新增、更新、无变化和远端缺失项；勾选后才执行。
- **识别地区**：解析节点域名得到公网 IP，再保存 ISO 国家代码与 ASN；不会改 URI。
- **打开原面板**：新窗口访问面板。
- **编辑 / 删除**：维护连接；删除连接前确认本地节点的处理方式。

2S-UI 通常需要先给入站绑定客户端，客户端才有订阅和分享链接；只有入站并不足以形成完整节点。S-UI 的模型可能不同，但 Wherever Station 同样只导入 API 实际返回的完整分享链接。

## 面板节点

展开面板卡片可查看节点。每项可以复制 URI、显示二维码或跳到节点库。节点仍由原面板维护协议、用户、证书和路由；Wherever Station 不反向修改这些配置。

## 远端删除处理

同步预览会列出本地存在但远端已消失的节点。可以停用并保留、删除本地记录，或脱离来源转成手动节点。默认不要静默删除，以防临时 API 或客户端绑定问题造成误删。

## 地区和服务器归属

外部面板节点可以不绑定 Wherever Station 服务器。自动地区识别是基于节点地址的数据库结果；若要按 VPS 分类，可在节点页给节点分配服务器。地区识别不代表物理机房的权威证明。
