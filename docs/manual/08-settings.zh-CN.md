# 8. 设置、备份与迁移

[上一章](07-providers.zh-CN.md) · [目录](README.zh-CN.md) · [下一章：工作流](09-workflows.zh-CN.md)

设置从右上角齿轮进入，保存跨页面配置。

## 订阅公开地址

公共根地址决定生成给客户端的订阅 URL。留空时使用当前 Komari 的 HTTP(S) Origin；反向代理或独立订阅域名时填写完整根地址，不要包含用户名、密码或末尾斜杠。修改后旧 Token 不变，但客户端看到的主机名会变化。

## 资源提示阈值

分别设置 CPU、内存和磁盘百分比。它们只控制服务器页的提示状态，不限制资源，也不会重启服务。单台服务器的套餐流量在服务器卡片“流量计划”中设置。

## 界面主题

**跟随 Komari**使用宿主主题；也可固定浅色或深色。主题保存在当前浏览器。

## 下载备份

备份包含服务器资料、节点 URI、订阅及 Token、订阅源、规则缓存、预设、托管实例元数据、Provider 连接及 API Token。它不包含 VPS 上的二进制、systemd unit、证书/私钥文件和 Komari Agent。备份文件等同于密钥，请勿公开上传。

部分内嵌浏览器会阻止下载：先打开全屏页；若点击仍无反应，使用页面给出的链接并右键“在新标签页打开”，触控设备长按。

## 恢复备份

选择 JSON 后先显示服务器、节点、订阅和实例数量的前后变化。确认后会**完整替换插件数据**，不会修改 VPS 文件或进程。若页面数据在预览后发生变化，恢复会拒绝执行，需重新选择文件。

## 迁移后核对

1. 确认新 Komari 中的 Agent Client ID 与服务器绑定。
2. 检查公共订阅根地址。
3. 检查证书绝对路径和托管实例状态。
4. 刷新服务状态，不要直接对不明实例执行启停。
5. 对关键节点运行连接检查，再让客户端使用新订阅。

备份恢复不负责移动证书与内核；需要完整迁移托管实例时，还应在 VPS 层备份 `/var/lib/proxy-console/` 和对应 systemd 配置。
