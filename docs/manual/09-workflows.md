# 9. Common workflows

[Previous](08-settings.md) · [Index](README.md)

## New VPS and managed node

Onboard the Agent, complete server metadata, create a Nowhere or sing-box instance, start it after review, open the firewall manually, run connectivity testing, add it to a subscription, preflight the target format, then copy the client URL.

## Airport subscription into your own output

Add and sync a Source, review its nodes and output switches, create a Subscription, select nodes by country/VPS, add groups/rules for structured clients, then use a device profile or preflight to copy the right URL.

## S-UI / 2S-UI

Create clients/share links in the original panel, connect the Provider, check then preview sync, identify regions if useful, assign server/tags in Nodes, and include them in a Wherever Station subscription. Continue to maintain protocol and certificates in the original panel.

## Adopt discovered Nowhere

Run discovery, import native Nowhere and stage a stopped managed copy. Review URI, version, certificate and configuration, switch adoption, then test connectivity. Restore the original service if needed.

## Move to another Komari

Download a plugin backup and separately back up host certificates, instance directories and units. Install Wherever Station on the new Komari, onboard Agents, restore after reviewing counts, rebind servers, verify public URL and paths, then refresh status and test connectivity.

## Publish screenshots

Enable privacy mode and avoid QR codes or backup content. Manually inspect subscription URLs, tokens, provider URLs, logs and error details: privacy mode is not a general-purpose redaction export.
