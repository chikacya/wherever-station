# 9. 常见工作流

[上一章](08-settings.zh-CN.md) · [目录](README.zh-CN.md)

## 从零接入一台 VPS 并部署节点

1. 服务器 → 接入新 VPS，运行 Agent 命令并刷新。
2. 编辑服务器资料，核对公网地址。
3. 部署节点 → 选择 Nowhere 或 sing-box，预览并创建。
4. 在实例卡片启动服务，确认防火墙端口。
5. 运行测试连接。
6. 加入订阅，在订阅页执行格式预检后复制客户端 URL。

## 导入机场订阅并输出自己的订阅

1. 订阅源 → 添加订阅源并立即同步。
2. 节点页筛选“订阅源”，核对名称、地区和输出开关。
3. 订阅页创建订阅，按国家或 VPS 选择节点。
4. 需要结构化客户端时配置代理组与规则。
5. 选择设备档案或运行预检，复制正确格式。

## 接入 2S-UI / S-UI

1. 在原面板创建客户端及分享链接。
2. 外部面板 → 连接专业面板，先检查再同步。
3. 在同步预览中确认新增、更新和缺失项。
4. 需要时识别地区，再到节点页分配服务器或标签。
5. 把节点纳入 Wherever Station 订阅；协议和证书仍回原面板维护。

## 把发现的 Nowhere 转为托管

1. 服务器或部署页打开发现扫描。
2. 导入原生 Nowhere 结果并建立停止状态的托管副本。
3. 在部署页核对客户端链接、版本、证书和配置。
4. 点击切换接管并测试连接。
5. 若异常，点击恢复原服务；不要手工同时启动两个占用相同端口的 unit。

## 迁移到另一套 Komari

1. 设置 → 下载备份，并另行备份 VPS 上证书、实例目录和 systemd 配置。
2. 在新 Komari 安装相同或更新版本的 Wherever Station。
3. 接入 Agent，记录新的 Client ID。
4. 设置 → 选择备份，核对预览后恢复。
5. 重新绑定服务器、检查公共地址和证书路径。
6. 依次刷新状态、连接检查、客户端订阅测试。

## 发布截图

开启节点页隐私模式，避开二维码和备份内容；仍需人工检查订阅 URL、Token、Provider URL、日志与错误详情。隐私模式不是脱敏导出工具。
