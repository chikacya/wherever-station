# Wherever Station user manual

[简体中文](README.zh-CN.md) · [Documentation overview](../USER_GUIDE.md)

This manual follows the actual interface. Read it in order for a first setup, or open the chapter for the tab you are using.

1. [Getting started](01-getting-started.md): entry paths, full screen, themes, privacy and drafts.
2. [Servers](02-servers.md): Agent onboarding, metrics, traffic plans, IP checks, discovery and services.
3. [Nodes](03-nodes.md): import, filters, bulk tools, connectivity, URIs and QR codes.
4. [Subscriptions](04-subscriptions.md): scope, groups, rules, quotas, devices, preflight and history.
5. [Sources](05-sources.md): upstream subscriptions, traffic metadata, deduplication and rule sets.
6. [Deploy](06-deployment.md): Nowhere, sing-box, presets, certificates, lifecycle, telemetry and adoption.
7. [Providers](07-providers.md): S-UI / 2S-UI connections and controlled synchronization.
8. [Settings and migration](08-settings.md): public URL, thresholds, themes, backup and restore.
9. [Common workflows](09-workflows.md): end-to-end recipes.

“Saved” usually means plugin data changed. Actions that modify a VPS are explicitly described as remote operations. A node being eligible for output does not prove network reachability, and a running process does not prove client connectivity. Treat URIs, QR codes, subscription URLs, provider tokens and backups as secrets.
