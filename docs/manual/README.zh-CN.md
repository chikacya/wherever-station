## 阅读约定

- “保存”只修改 Wherever Station 数据；涉及 VPS 的操作会明确写出“远程执行”。
- “节点可输出”表示它可进入订阅，不代表网络一定可用。
- “服务运行”表示进程存在，不代表客户端一定能连接。
- URI、二维码、订阅 URL、Provider Token 和备份均可能包含凭据，请按密钥对待。

遇到运行错误时参阅[排错指南](../TROUBLESHOOTING.zh-CN.md)；协议转换范围参阅[协议支持](../PROTOCOLS.zh-CN.md)。
